Quick start

From zero to first Discord change in 2 minutes

Three steps. No config files, no YAML, no clicking through dashboards. The setup wizard handles everything in chat.

1
Install the plugin inside Claude Code
Run these two commands. Then fully quit and reopen Claude Code — the plugin loads on restart.
Claude Code terminal
/plugin marketplace add JCodesMore/jcodesmore-plugins
/plugin install discord@jcodesmore-plugins
→No Claude Code yet? claude.ai/download — free to install.
2
Connect your Discord bot — one command, wizard does the rest
Claude walks you through creating a bot or using one you already own. Takes about 60 seconds.
Claude Code chat
/discord:setup
1.Claude opens discord.com/developers/applications → New Application
2.Bot tab → Reset Token → Copy → paste into chat
3.Claude verifies the token, generates an invite URL, adds bot to your server
4.Pick which server to manage → done ✓
→Already have a bot token? Paste it at step 2. The wizard skips what's already configured.
3
Describe what you want — and it's done
Type /discord then describe anything. Click any example below to copy it.
/discord make me a server for my AI research community
/discord create a #announcements channel under an Info category
/discord add a Moderator role — blurple, hoisted, with kick and ban perms
/discord apply the startup-team template to my server
/discord block profanity and mention-spam in all channels
Why it works

Designed around the way you actually think

⚡
No Discord UI required
Every setting Discord exposes via REST is accessible through natural language. Channels, roles, permissions, AutoMod, welcome screens — all in chat.
🏗
Architect agent for full servers
Open-ended requests spawn a dedicated architect agent. Describe a community type, get a full structure: roles, categories, channels, AutoMod, welcome screen — applied atomically.
🔒
Your bot, your token
Nothing talks to a third-party server. Your bot token lives in Claude Code's local plugin data directory on your machine. Plaintext — scoped to your machine only.
🔄
Safe by default
Template applications are idempotent — existing channels/roles are skipped by name. The architect agent dry-runs and previews before applying. Destructive actions require explicit intent.
⚙️
30s TTL cache
Channels and roles are cached within each session. Multi-step flows — "list → resolve ID → create" — hit the API once, not five times. Cache invalidates automatically on mutations.
🛡
Rate-limit safe
Built on @discordjs/rest, which handles Discord's bucket-based rate limits with automatic retry and 429 back-off. No handmade retry logic needed.
🤖
Bot ecosystem deploy kit
The Claw Bots GTM package ships deploy.sh + register_commands.sh (24 slash commands, idempotent PUT) + interactive setup wizard for PicoClaw & OpenClaw on Fly.io.
